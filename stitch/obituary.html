What actually happens

In case you were curious. Or suspicious. Here is our internal orchestration flow.

01
BugAnalyzer

Deciphers human frustration into logical errors.

Uses Claude 3.5 Sonnet to map bug reports to specific functional requirements and potential stack traces.

02
CodeSearch

Infiltrates the repository to find suspects.

Executes targeted semantic searches and explores file hierarchies using octokit and simple-git.

"If TestRunner fails... Max 3 tries... Even robots know when to ask for help."

03
FixGenerator

Drafts the technical obituary for the bug.

Writes clean, idiomatic code patches adhering to your existing repository style and linting rules.

04
PRCreator

Submits the final report for review.

Opens a GitHub Pull Request with a detailed summary of the fix, test results, and a small joke about Javascript.
